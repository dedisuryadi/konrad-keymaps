# Konrad XIAO RP2040 Split

A handwired 40-key split KLOR Konrad, powered by one Seeed Studio XIAO RP2040
per half. The same firmware is flashed to both halves; the left half is the
fixed USB master.

Build with the runner at the root of this keymap package:

```sh
./build.sh
```

See the package [README](../../../README.md) for the matrix, split-connector
wiring, key assignments, and flashing instructions.
